# image-compressor

ImageCompressor is a CL-tool designed for efficient image compression without visible quality loss. The application features an intuitive TUI with keyboard navigation, making it easy to process both individual files and entire directories.

Key capabilities include support for multiple image formats (PNG, JPG, JPEG, BMP, TIFF, WebP), integration with pngquant for optimal PNG compression, customizable quality settings, and detailed compression statistics. The tool achieves up to 70% file size reduction while maintaining visually lossless quality.

Built with Python and Pillow, ImageCompressor runs seamlessly on Windows, Linux, and macOS.
